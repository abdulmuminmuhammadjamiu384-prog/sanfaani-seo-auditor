Audit Methodology & Limitations

This auditor inspects on-page SEO health and baseline technical performance:

  • Server Responsiveness: Verifies HTTP 200 responses and connection latency.
  • Title & Meta Tag Quality: Evaluates optimal character limits (10-70 chars for titles, 50-160 for descriptions).
  • Heading Hierarchy: Ensures one clear, unambiguous <h1> tag per landing page.
  • Image Accessibility: Checks for presence of meaningful descriptive alt tags.
  • Internal Navigation: Probes internal hyperlink health to identify broken paths.

Acknowledged Limitations

Dynamic Single Page Applications (SPAs) relying heavily on client-side JavaScript rendering may not expose elements during raw HTTP parsing without headless browser rendering.
